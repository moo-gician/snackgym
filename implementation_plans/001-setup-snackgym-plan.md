# [Goal Description]
스낵짐(SnackGym) 프로젝트 기획 구체화 및 핵심 4대 문서(`./plan.md`, `./todo.md`, `./context.md`, `./design.md`) 셋업.

**[Mission Statement : Pump Up Your Energy]**
*   **[약속] Promise**: 졸음이 쏟아지는 시간, 알람을 듣고 사내 체육관에서 가볍게 몇 세트! 빵빵해진 근육(Pumped Up)과 기분 좋은 에너지로 책상에 돌아오십시오.
*   **[문제] Problem**: 거창한 목표(할당량)를 채워야 한다는 부담감 때문에 운동을 시작조차 하지 못하는 직장인들의 스트레스.
*   **[통념] Conventional Wisdom**: 직장인에게 진짜 필요한 건 억지로 채우는 무거운 목표가 아니라 스트레스 없는 '가벼운 환기'입니다.
*   **[원인] Cause**: 당신이 운동을 포기한 이유는 완벽하게 해내야 한다는 압박감이 당신을 짓눌렀기 때문입니다.
*   **[해법] Solution**: 할당량 부담 제로! 웹앱에서 루틴을 고르고, 알람이 울리면 그저 한 세트 즐기고 버튼 하나만 누르면 끝입니다.
*   **[자각] Awakening**: 더 이상 할당량에 쫓기지 마십시오. 짧은 시간 기분 좋게 땀 흘리고 활력을 얻어 업무 효율이 극대화되는 일상을 즐기십시오.

## Proposed Changes
승인 즉시 프로젝트 루트(`./`)에 아래 문서를 작성합니다.

### 1. [NEW] `./plan.md` (기획 및 코어 로직)
*   **Pump Up & Refresh**: 할당량 부담을 없애고 긍정적인 에너지를 채우는 미션 스테이트먼트 유지.
*   **[Phase 1 확정] 플랫폼 전략**: **모바일 웹앱(구글 Auth)** 중심 + 텔레그램은 '알람 수신 및 1초 완료' 용도로만 활용하여 최소 비용으로 가장 빠르게 시장(PMF) 검증.
*   **게이미피케이션 최소 기준**: 무거운 볼륨(kg) 계산은 폐지하되, '연속 달성일(Streak)' 유지를 위한 **"하루 최소 2~3회 세션 완료"**라는 최소 달성 횟수 기준을 도입하여 유저의 동기부여 유지.
*   **보안 연동 프로세스 (OTP Handshake)**: 텔레그램 디프링크 계정 도용(Hijacking)을 막기 위해 웹앱에서 발급한 **5분 만료 일회성 보안 토큰(OTP)**을 Cloud Functions에서 검증하여 매핑.

### 2. [NEW] `./context.md` (아키텍처 및 DB 스키마)
*   **프론트엔드 스택**: **Vite + React (TypeScript) + Tailwind CSS** 단일 페이지 앱(SPA) 아키텍처 확정.
*   **이벤트 기반 스케줄링 & 스로틀링**:
    *   Firestore 요금 방어를 위해 **Google Cloud Tasks**를 활용한 정확한 이벤트 예약 발송 체제 구축.
    *   텔레그램 API 전송 제한 방어를 위해 **속도 제한 스로틀링(Throttling Queue)** 알고리즘 강제.
*   **Firestore 이중 아키텍처**: 
    *   당일 묶음 문서(`daily_workout_sessions`)에는 합산 통계만 기록.
    *   세부 로그는 하위 컬렉션(`logs`)으로 물리적 분리.
*   **[Phase 2 고려] 미래 확장성**: 향후 Capacitor를 활용해 현재 웹앱 코드를 100% 재사용하여 안드로이드/iOS 네이티브 앱으로 패키징하고, 서버비용 없는 로컬 푸시 알람으로 전환할 수 있는 가능성 명시.

### 3. [NEW] `./design.md` (디자인 시스템)
*   **카드 뒤집기(Flip) 단일화**: 나란히 배치(Side-by-Side)를 폐기하고, 앞뒤 중 한 면만 노출되는 **싱글 뷰**로 UI 통일. 
*   **인지적 동기화**: 후면 근육이 켜졌을 때 전면 실루엣 주변에 '후면 활성 네온 오라(Neon Aura)' 효과를 주어 직관적으로 뒤집기를 유도.
*   **텔레그램 봇 템플릿**: 알림 텍스트 포맷, 이모지, 버튼 레이아웃 명세.

### 4. [NEW] `./todo.md` (백로그 및 E2E 테스트)
*   Vite/React 기반 빌드, OTP 핸드셰이크 검증 봇 백엔드, Cloud Tasks 워커 설계 태스크 분배.
*   **E2E 테스트 시나리오 보강**:
    *   OTP 토큰 임의 변경을 통한 텔레그램 계정 하이재킹 에러 반환 방어 테스트.
    *   대규모 알람 발송 시 Cloud Tasks 스로틀링 큐 정상 작동 시뮬레이션.
